# 课程体验

## 模式

课程首页、讲义：Read。作业、薄执行页与教师反馈：Operate。

## 已确认的目标

客户或领导汇报。默认学员，把课程内容与可执行作业作为第一层体验。用户最新要求所有单元自由访问，默认带入课题和前置样例，不设置学习前置锁。

## 方向契约

保留现有仓库的米白与深绿色基调，使用课程读物的排版层级。默认首页直接呈现课程名称、学习内容、教师、课程大纲与资料。首屏以课程为中心，教师功能从课程内进入。

主色为原仓库的深绿 #0e3d2c；画布 #fbfaf6，正文 #23352b，辅助文字 #5e6b5b，分隔线 #e0e3d8。辅助文字在主要纸面及浅色块上的对比度为 4.53—5.58:1。字体显式支持中文；标题采用宋体风格衬线，正文与控件用系统中文无衬线。

署名、文献和课题来自源文档或明确的 Mock 课包。科研插画和教学图由本地 SVG 编写。无 CDN 或图片外链。

## 关键交互

任一作业可直接打开，带入同一课题与任务。课程网页生成和编辑 Prompt，首屏明确展示“前往端砚执行”；端砚只执行标准 Agent 任务并返回结果。交付物取回原作业网页后，再在网页检查、优化和手动提交。老师从同一提交查看产物与执行记录，AI 仅建议，最终反馈人工点击。样例补齐入口使教师流程可独立体验。

## 质量范围

检查桌面、320、390、768、1024 宽度；工作与反馈页包含桌面及窄屏证据。无成绩册、证书或学生回流 KPI。Mock 放页脚及相关结果旁。
