# 端砚学院 · 课程与科研资产 Demo v0.6

面向客户或领导汇报的 React 前端。默认学员课程，保留同一 PD-1／PD-L1 课题的讲义、Q1、问题界定、论文与机制图。全部单元自由访问。课程、产物、工具轨迹、授权、质量分和指标均为 Mock。

在线预览：https://xjinya-xiangwu.github.io/Duanyan-academy-demo/

最新需求：[Demo PRD v0.6](docs/demo-prd-v0.6.md)。飞书现有 PRD：https://aicarrier.feishu.cn/docx/W8Fzd2e6toGBZLxr5cCcpovYnsh 。本轮以 2026-11-16 读取的课程项目规划 revision 304 和课程规划优化版 revision 34 为依据，保留云端 v0.5 revision 19 的教师端范围。

## 可操作路径

1. 直接进入任一单元，在网页生成或编辑 Prompt，点击首屏“前往端砚执行”。
2. 端砚薄页接收任务、执行 Agent、返回结果；在原网页编辑、优化后手动提交。
3. 教师工作台提供环节配置、作业管理、布置发布、科研资产数据集。配置可改现有课时/Q1/三份作业的标题、说明和要求；不能关闭任务执行绕过履约。
4. 教师查看产物和同提交轨迹、写评论，通过或请修改。AI 建议只辅助；旧提交与评论保留。
5. 学员默认仅教学用途；可主动选择训练研究用途或撤回。教师和高校授权分开模拟，不替学员授权。
6. 教师做结构检查、十维质量复核，再审核候选。授权未齐、敏感待审、T5 留出评测、低质量、新版本未审或任务要求变更均阻断。撤回立即排除候选，不改变课程反馈。
7. 数据集按单元、状态、事件类型和文本筛选；学员也可下载自己的 Mock JSON 资产包，包含任务输入、原始执行稿、最终稿、版本、反馈和权限。
8. 从课程首页浏览真实课题两条路径。三份作业获教师通过后才可演示申请；导师审核只表示接收演示，不签发证书。

教师班级进度可“载入完整提交样例”，不覆盖已有提交和反馈。入课有效码：生医6-DEMO；名单：林可。缺少三份强制作业仍阻断课程发布。

## 指标与资产边界

北极星对齐“验证通过并映射模型能力目标的科研任务轨迹资产包数量与质量加权”。前端按每任务最新版本去重，十维均分 / 5 仅作演示权重。旧版优化/回传/AI 评估事件数保留为辅助核对。

所有导出包标记 provenance=synthetic_demo、training_used=false。真实 tool_calls 为空。结构检查只能检查标记和记录，不能验证引用真实性、科学正确性、真实复现或模型提升。T2/T3/T5 是流程演示；无真实 T4 RL 环境包。

默认教学与训练授权解耦；任何撤回只影响候选流程。下载副本需用户另行管理，网页撤回无法删除下载副本。旧 v0.4 浏览器进度保留，但缺新版规范字段的旧提交不会被假定为合格候选。

## 课程与未实现范围

课程结构展示：大师课无证书；学分课含模拟训练、规划为 16 周与 2—3 学分；其后真实课题实战分自带课题/导师双选；真实成果可复现验收后才满足唯一实战证书条件。

当前生医课是片段样例，未实现完整 16 周通识或专业课程、真实端砚跳转、模型、账号权限、有效协议、临床/未公开数据处理、真实训练入库、训练日志、环境重放或证书签发。两份源规划中的市场价格未独立核实；项目规划的两张嵌入 Sheet 缺少用户读取 scope，未用于本次规格。

## 开发与核验

    npm ci
    npm test
    npm run build
    npx playwright install chromium
    npm run test:e2e
    npm run bundle:offline -- <输出路径>

现有 React 18、TypeScript、Vite、hash 路由和相对资源路径；无新依赖。单文件离线版内嵌 JS/CSS/SVG，无 CDN 或模型请求。文献链接仅用户点击时访问。

Playwright 启动独立 5178 服务，不能复用旧服务器；截图保存在 test-results/screenshots 或 SCREENSHOT_DIR。GitHub Actions 在 main 提交后运行单元测试、构建并发布 Pages。发布结果以实际 Actions 和线上回读为准；Pages 仍是前端预览。
