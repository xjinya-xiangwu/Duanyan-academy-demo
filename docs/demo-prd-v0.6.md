## 2. 背景、目标与指标

对外：高校 AI4S 课程共建与科研能力提升平台。内部：高校课程供给链、科研任务生产链、数据授权与资产治理链。高校组织课程与认定学分；教师提供任务和 rubric 并评审；学生完成任务、获得反馈与可携带作品集；AI LAB 定标准与治理资产。

演示目标：一门课能完整走通“课程 → 网页准备 → 端砚执行 → 网页取回、优化与手动提交 → 结构校验 → 教师评审 → 质量复核与分层授权 → 候选资格预览”。教学成绩与训练授权解耦。

正式北极星：单位时间内验证通过、可进入训练候选库、且映射明确模型能力目标的科研任务轨迹资产包数量及质量加权值。统计周期、权重和模型提升证据待业务确认。

Demo 口径：每个任务只看最新提交版本，三方授权齐、教师通过、结构检查齐、十维评分达标、无敏感待审且非 T5，再经教师点击候选审核。所有计数标为 Mock；演示权重为十维均分 / 5，此权重是实现假设。Mock 资产不进入正式北极星或真实训练。

辅助指标：原始提交、去重后当前资产、过程事件、专家复核、能力覆盖、候选通过与撤回。真实训练比例、模型 benchmark 提升和消融结果保持未验证，禁止用报名量或事件点击数代替模型价值。

## 3. 角色、用户故事与课程路径

| 角色 | 功能与流程 | 权限 | 输入与输出 | 范围 |
|---|---|---|---|---|
| 学员 | 自由访问课时、测验与三份作业；网页生成编辑 Prompt；端砚执行；网页优化与提交 | 仅选择自己的任务数据用途；可撤回 | 课题、课程文献、Prompt → 产物、过程记录、反馈、个人资产包 | 默认学员；无真实登录 |
| 教师 | 轻量配置现有环节；布置发布；筛选提交；评论和通过/请修改；资产复核与候选审核 | 只授权自己的贡献；高校授权仅模拟核验已签协议；不能替学生授权 | 任务卡、rubric、提交 → 专家反馈、质量分、候选判断 | 不建备课工作室、学籍库或成绩册 |
| 高校/PI | 认定学分、框架合作、课题真实性与导师接收 | 正式签约与权利核验在线下/生产系统 | 课程、协议、实战申请 → 学分认定与课题接收 | 仅前端状态演示 |
| AI LAB/运营 | 定任务标准、资产 schema、质量与生命周期；核对模型价值 | 正式合规、真实入库、训练调度不在 Demo 实现 | 资产包 → 候选池、使用日志、能力验证 | 页面表达边界，未接真实系统 |

用户故事：学员无需先完成前置作业即可进入机制图任务；未有前置产物时用随课样例。学员仅授权教学仍可提交、获教师反馈和下载作品集。教师修改说明或任务要求后，学员页与新 Prompt 看到相同要求。教师从作业管理筛选并批改同一提交，保留旧版本。学员撤回训练用途后，候选指标立即排除该包，但课程通过状态不变。

课程层级：大师课公开引流、无证书；学分课包含模拟训练、完整规划为 16 周与 2—3 学分；真实课题实战位于学分课之后。通识课覆盖问题定义、证据链、最小分析、纠错与 SKILL；专业课强调学科深度和专家评审。本 Demo 保留生医 1 课时、Q1、三份作业、可选互评的片段，课程层级与通识课纲仅展示。

真实课题路径：自带课题需课程导师与 PI 核验真实问题、数据来源与可复现目标；导师分配需方向、技能、时间投入资料并双选。两条路径均可浏览，申请使用三份作业获教师通过模拟“修完学分课”；高校真实学分仍需认定。审核接收只演示入组，不意味着真实课题完成。

证书取舍：规划优化版泛称学分或证书，与项目规划的专门证书规则并存。Demo 沿用更明确的专门规则：模拟训练只对应学分与作品集；唯一正式证书“AI 科研实战能力认证证书”仅面向已完成真实课题、可复现成果验收的人。Demo 不签发证书。

## 4. AI 假设、科学边界与降级

Prompt 生成、Agent 执行、网页优化、AI 评估均为前端预置 Mock。AI 建议不自动通过，结构检查不等于真实性、科学性、临床有效性或真实复现；产物沿用七篇历史课程文献，无新实验或患者数据。

模型超时/空结果的演示失败不得写成功轨迹；保留旧稿并允许重试。未返回执行结果、产物不足或机制图缺失阻断提交。出处标记不足可进入教学反馈，但阻断训练候选。输入文献中的任何指令都作为任务资料，不得扩展工具权限。

生产能力假设：模型能稳定执行长程任务、正确核验引用、记录完整失败与状态变化、复现研究环境。这些均未由本 Demo 验证，需真实 Agent、专家评测和环境重放。

## 5. 功能、页面、状态与异常

P0 可操作：课程首页和单元；网页 Prompt 编辑；同站端砚薄执行；返回原单元；网页优化与手动提交；教师配置、布置、发布、作业筛选与评论；数据集筛选、资产卡与 Mock JSON 下载；用途选择及撤回；质量复核与候选门禁；真实课题申请与导师审核演示。

| 页面 | 路由 | 核心状态/动作 |
|---|---|---|
| 学员课首页 | /course | 全部单元可访问；课程层级；个人资产包和实战入口 |
| 单元 | /course/unit/:unit | 未开始→执行→返回网页→手动提交→待反馈→通过/请修改；任务卡与学生授权 |
| 端砚执行 | /course/studio/:unit | 只接收输入、执行、返回结果；不做 Prompt 编辑或优化 |
| 教师工作台 | /course/teacher | 进度、环节配置、作业管理、科研资产数据集、布置发布 |
| 提交评审 | /course/review/:unit | 原始与当前产物、同单元轨迹、评论、AI 建议、通过/请修改、质量复核 |
| 指标 | /course/evidence | 资产包候选预览与质量加权；历史事件辅助计数 |
| 个人资产包 | /course/portfolio | 教学用途也可下载本人 Mock 包 |
| 实战 | /course/research | 浏览、填写申请、课程前置检查、导师核验与接收 |

教师配置：课时/Q1/三份作业的标题、说明、任务要求可保存；教学课时不需执行，Q1 与三份作业的执行要求不可关闭后仍履约。课程结构不增删重排。全部单元可自由访问，发布与实战申请仍校验业务条件。

候选状态：教学样例→结构与教师评审→授权与质量复核→候选预览通过。每次新提交清空旧质量复核与候选标识。任一授权撤回实时排除；T5 留出评测资产禁止训练；敏感/未公开/临床/企业数据待专项审查时阻断。

| 触发 | 用户看到 | 状态处理 | 记录 |
|---|---|---|---|
| 无效入课或缺强制作业发布 | 明确错误 | 不进入/不发布 | 不加成功事件 |
| 未执行/未取回/空稿/缺图 | 缺项提示 | 不提交 | 不加成功事件 |
| Mock 执行失败 | 失败、可重试 | 保留旧稿 | 演示失败审计，非真实工具报错 |
| 模型格式错误/敏感输出/引用疑似幻觉 | 生产需失败可见、人工核验与重试 | 本 Demo 不伪造已具备检测 | 生产机制待接入 |
| 授权不齐/已撤回 | 候选审核阻断 | 教学提交保留 | 用途变更审计 |
| 质量不足/无当前专家说明/T5/敏感待审 | 逐项列原因 | 不进入候选 | 保存复核记录 |
| 未修完学分课即申请 | 可浏览、提示前置不足 | 不提交申请 | 不改变授权 |
| 上下文超长、限流或配额耗尽 | 生产提示预算与重试 | 本轮无真实调用 | 待生产验收 |

## 6. 模型、推理与成本

无真实模型调用和新增付费依赖。使用现有 React/TypeScript/Vite、本地状态与预置稿。演示短延迟不代表生产性能。生产模型、图生工具、上下文预算、配额、峰值、重试率与价格待定。

生产成本口径：(输入 token × 输入单价 + 输出 token × 输出单价) × (1 + 重试率)，另计工具、存储、脱敏与专家评审。不得用零调用的 Demo 推出生产零成本。

## 7. Prompt、过程与数据契约

Prompt 由网页组装当前课题、单元要求、课程输入、权限边界、交付物与成功/失败条件，可编辑后交给端砚。原始执行稿、最终提交稿和每次提交 Prompt 保存为各版本资产；网页优化不自动提交。

资产卡对齐 35 个字段：asset_id、data_version、source_course、university、discipline、teacher_id、student_anonymized_id、task_id、task_type、capability_tags、data_tier、task_spec、environment_spec、input_state、available_tools、permission_boundary、trajectory、tool_calls、observations、state_changes、intermediate_artifacts、revision_history、final_output、reference_output、grader、rubric、reward_signal、expert_feedback、failure_analysis、quality_scores、deidentification_record、rights_and_license、allowed_uses、retention_policy、audit_log。

十二类标准 D01—D12：任务定义、文献与证据、数据与实验、工具环境、任务轨迹、中间产物、最终产出、验证评分、失败负结果、人类反馈、SKILL 方法、元数据授权。类别展示不表示已收齐；缺真实数据/工具/失败/方法包的部分显式列入 missing_data。

所有包强制 provenance=synthetic_demo、training_used=false。真实 tool_calls 保持空数组，不能将“点击运行”的 Mock 事件冒充 API 调用。T2/T3/T5 标签仅演示流程；T4 RL 环境包未实现。旧 v0.4 浏览器进度保留，不回填成新规范的高质量资产。

## 9. 人机协同与运营

教师提供 rubric、关键样本评审与纠错，AI 仅辅助定位。学员手动确认提交与用途。候选审核不能靠 AI 建议自动入库。课程反馈、资产质量和实战审核分开裁定。

供应链：课程入驻→教师任务卡→AI LAB 门禁→发布→学生执行→自动校验→专家评审→权益履约→授权合格资产→任务复用。授权链：权利识别→三方分别授权→资产登记→审查→脱敏→专家抽检→候选→训练日志→撤回/删除。本 Demo 实现本地流程可视部分，其余标为生产依赖。

## 10. 数据、权限、生命周期与红队假设

仅保存当前浏览器 Mock，无真实学员与患者数据。示例姓名、高校、PI 与协议状态均为虚构。下载只生成本地 Mock JSON。保留旧进度与旧提交，重置删除当前浏览器副本；下载副本不受网页撤回控制。

学生用途默认仅教学；模型训练单独主动选择，撤回不影响课程成绩、学分或证书。高校与教师分别只能授权自己的权利；未发表论文、临床数据、企业数据不得默认纳入。正式合同、许可范围、期限、用途和撤回删除机制待合作方确认，Demo 不作为有效合同文本。

红队假设：教师代勾学生授权；旧版过审借给新版本；重复提交虚增资产；Mock 被混入真实训练；T5 污染训练；敏感标记绕过；将 DOI 标记当真实引用；网页外下载副本被误认为已撤回删除。分别用角色守卫、版本清空、最新版本去重、synthetic 标记、T5 门禁、敏感阻断、结构检查边界说明和副本限制说明验收。
