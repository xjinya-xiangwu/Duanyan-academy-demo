# 端砚学院 · 课程体验 Demo v0.4

面向客户或领导汇报的交互式前端：默认进入学员课程首页，一门 PD-1／PD-L1 生医课贯穿讲义、Q1、问题界定、论文和机制图作业。课题、课程、学生、产物、AI 建议、执行记录和指标数字均为 Mock。

## 最新演示要求

用户在 2026-11-11 明确要求取消访问前置依赖。所有课时、测验与作业均可直接进入，不要求先读完讲义、答完测验或交前一份作业。示例课题默认带入，缺少前置产物时使用随课示例。

教师视图提供“载入完整提交样例”，可以补齐缺少的提交后直接体验反馈。已有提交与反馈会保留。

## 直接体验

网页入口：https://xjinya-xiangwu.github.io/Duanyan-academy-demo/

交付的 Duanyan-Academy-Demo.html 是单文件版本。代码、样式与 SVG 图均内嵌，无 CDN、远程字体或真实模型请求。文献 DOI 只在用户点击时打开外部页面。单文件已通过本地 HTTP 预览检查；内置浏览器不允许 file://，未自动验证双击打开。

进度保存在当前浏览器。页脚“演示设置”可重置进度或补齐样例。

## 可操作的路径

1. 进入课程，直接选择任一课时、测验或作业。
2. 在作业／测验网页生成和编辑 Prompt，点击首屏的“前往端砚执行”。端砚只接收任务、运行 Agent 并返回结果。
3. 从端砚取回结果，在原课程网页检查、优化与编辑交付物，再手动提交。取回结果不等于已交作业。
4. 从课内切换教师视图，查看同一提交的产物与执行记录。
5. 生成可选 AI 建议，再由老师点击“通过”或填写意见后点击“请修改”。
6. 学员按反馈重新执行、回传，老师再次反馈。旧提交与意见保留。

Q1 概念题可自测，不阻挡短实训。可选互评只展示反思问题。

## 教师布置

选用生医模板，生成邀请码或导入 Mock 名单，然后发布。缺少问题界定、论文、机制图中的任一强制作业时，发布仍会被阻断。导航自由访问与业务条件校验分别处理。

示例邀请码：生医6-DEMO。示例名单：林可。入课页可演示无效邀请码或非名单拒绝。

## 计数口径

仅在教师视图的“回流说明”中显示指标，不出现在学员首页。

- Q1 与问题界定首次合法回传计入“实训执行／产物回传”。
- 论文和机制图首次回传计入“后续作业再回传”。
- 每个单元最多计前两次成功的网页交付物优化。
- 每个单元同一次提交的 AI 评估只计一次。
- 同一单元重复回传不叠加，退回修改不扣已有计数。
- 阅读、课页勾选、只打开执行页、空结果、失败操作、无效邀请码均不计。
- AI 建议不自动通过；取回结果、网页优化均不自动提交作业。

## 来源与边界

依据：Demo PRD v0.4（revision 13）、课程调研（读取 revision 813）、产品设计（revision 8），加上本次会话关于自由访问和网页／端砚职责的最新要求。

没有真实后端、账号权限、端砚客户端跳转、模型调用、云端轨迹入库或生产运行验证。没有成绩册、分数、证书、商城、SIS 或完整创作台。

## 开发

沿用 React 18、TypeScript、Vite 和 React Router；使用 hash 路由与相对资源路径，支持子目录静态托管。

    npm ci
    npm run dev
    npm test
    npm run build
    npm run bundle:offline

bundle:offline 默认把单文件写到本任务 outputs 目录，也可在命令后传入一个输出路径。

浏览器自动检查脚本位于 e2e，截图目录用 SCREENSHOT_DIR 或 test-results/screenshots，未写死平台路径。
