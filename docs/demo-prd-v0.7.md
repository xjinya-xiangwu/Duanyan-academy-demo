## 2. 最终成品定义与指标

核心成品是一条可复核的科研任务轨迹 JSONL 记录。每行一个完整任务资产，含任务约束与输入、工具环境版本、Prompt 模板、多个执行批次、步骤输入/输出/观察、失败与纠错、产物版本、学生/教师/AI 标注、最终字段、质量核验和 lineage。

样例交付：high-quality-trajectories-v0.7.jsonl，恰好两行。HQ-TRACE-001 为论文证据链纠错，HQ-TRACE-002 为机制图对象/关系/边界修正。每条包含 2 次执行、3 个产物版本、学生 2 轮与教师 2 轮标注；每轮涵盖六个结构字段。全量 provenance=synthetic_demo、training_used=false，所有工具运行和专家审核均为模拟。

“高质量”在本轮指结构完整、版本与标注可回溯、失败纠错链可核、终稿字段可看懂；不证明真实科学正确性、真实专家金标、真实复现或训练收益。正式北极星仍是经真实验证且映射能力目标的资产包数量与质量；样例不能纳入真实北极星。

辅助验收指标：当前任务运行记录独立；人工标注作者/轮次/产物版本/区块/字段完整；AI 建议和人工确认保留对应引用；终稿字段以人工确认更新；JSONL 两行均可解析并通过引用完整性检查。

## 3. 从成品字段倒推角色与旅程

| 成品需要 | 用户功能 | 角色/权限 | 输入→输出 |
|---|---|---|---|
| 任务 spec 与目标能力 | 配置现有任务、成功/失败条件与 rubric | 教师 | 课程要求→任务卡 |
| Prompt 模板与字段 schema | AI 生成标注 Prompt，教师编辑确认 | 教师人工确认 | 任务要求→版本化模板与六字段 |
| runs、工具、观察与失败链 | 端砚执行，显示本批次轨迹与检查器 | 学生执行；端砚仅执行返回 | 网页任务→工具/Agent 步骤与产物 |
| 区块、字段和学生判断 | 交付物工作区，点击区块，AI 提字段、学生确认 | 学生只能标注自己的当前产物 | AI 建议→人工自标注与提交 |
| 专家纠错和判断 | 教师查看同版产物及轨迹，AI 提建议、人工修改确认 | 教师只能评审当前提交版本 | 提交/AI 建议→教师标注、评论与通过/请修改 |
| 多轮 revision 与 lineage | 学生按教师反馈重做/优化，新版再次自标注与提交 | 各角色新增记录，不覆盖历史 | v1→v2→v3，旧判断保留 |
| 最终字段和完整成品 | 合并当前版本人工字段、查看质量与 JSONL | 教师审核、学生可看本人资产 | 轨迹+版本+标注→最终资产包 |

正常旅程：教师任务要求→AI 标注模板→教师确认→学生网页准备任务→端砚执行并记录工具/观察/失败修正→返回交付物工作区→AI 字段建议→学生逐项改/确认→提交→教师 AI 辅助定位→教师人工标注与反馈→学生修订并再提交→教师确认终稿→查看最终轨迹资产并导出。

## 4. AI 与 Mock 边界

AI 仅生成建议：标注 Prompt、六字段、评审要点。教师模板确认、学生自标注和教师标注均由人操作；AI 建议不计人工标注、不自动提交、不自动通过。模型调用、工具调用、耗时、样例专家评审全为前端 Mock。生产模型效果、成本与延迟未实测。

默认回传是本轮 Demo 的任务数据收集规则：无需每任务授权选择，移除“这份任务数据，如何使用”和三方勾选。范围为任务输入、工具轨迹、中间/最终产物、失败与修订、学生/教师标注。当前只在浏览器状态与导出样例中模拟回传，未接真实云端。不得据此声称真实患者/未公开/企业数据拥有训练使用权；生产协议与真实训练仍待验证。

## 5. 页面、功能与状态

端砚运行记录：批次选择、当前批次为默认、轮次折叠、工具父子层级、模拟时间概览、搜索、点击步骤查看输入/输出/关联产物。失败显示失败，旧批次可切换；真实秒数未知不能编造。记录不负责编辑 Prompt 或优化交付物。

交付物工作区：深绿产物标题带、当前版本、人工标注数量、段落区块号、点击高亮、图与图注标注入口、结构化字段建议、人工标注表单、历史轮次。宽屏正文与标注侧栏并列；窄屏顺排。交付物区域优先于普通日志说明，避免稿件散落在普通详情段落中。

教师轻量配置增加“任务发布前准备标注模板”：AI 生成→编辑→教师确认；字段 schema 展示。教师评审页展示突出交付物+AI/人工标注+原通过/请修改+完整轨迹。数据集顶部展示最终成品区，两个样例可切换，分别看终稿、轨迹、多轮标注、JSONL，统一下载。

原课程默认学员、所有单元自由访问、网页负责 Prompt/优化、端砚仅执行返回、手动提交、强制作业发布和实战申请条件全部保留。移除授权交互不移除质量审核：当前版本需学生及教师人工标注、教师通过、结构核验与质量门槛；T5 与敏感待审仍阻断候选。两条静态优质样例与用户操作数据分别展示，不能把预置样例偷偷当作用户完成量。

## 6. 模型与成本

沿用现有 React/TypeScript/Vite，无新付费接口。AI 模板和字段用预置建议；Harness 仅为 UI 参考。生产模型选型、输入/输出 token、重试、工具成本、专家审核工作量待实测，不从 Demo 推出真实性能和零成本。

## 7. 字段、事件、版本与导出契约

六个字段：research_question、claim、evidence_doi、evidence_level、limitation、revision_reason。每条人工或 AI 标注需 annotation id、unit、artifactVersion、blockId、field、author、round、value、rationale、status、proposalId、time。AI status=proposed，人工作为新记录 status=confirmed，不改写 AI 原条。

执行记录：run id、unit、version、provenance、annotationTemplate 快照、steps。步骤含 id、parentId、round、actor、kind、title、startMs、durationMs（可缺）、status、input、output、artifacts。输出包含失败详情和决策摘要，不含私密凭证或隐藏思维链。

产物版本：每次执行、优化或内容变化保存新 artifactVersion 与完整内容，旧标注仍锚定旧版区块。当前版本区块按分段生成稳定于该版的 block id；跨版不自动迁移标注，以免锚点漂移。历史 v0.4/v0.6 迁移只保留已有产物，不补造不存在的运行或标注。

最终字段以当前版本已确认人工记录覆盖 AI 建议，保留所有原建议和历史判断。候选审核后新的人工标注、提交或配置变更需重新审核。两条成品 JSONL 每行完整对象，包含 final_output、artifact_versions、annotations、runs、verification、failure_analysis、lineage 和 collection_policy。

## 8. 验收与异常

| 验收 | 可判定门槛 |
|---|---|
| 轨迹 | 运行一次出现本批次步骤；可查看失败输入输出；重跑保留旧批次；轮次与工具层级可见 |
| 授权移除 | 学生和教师页无逐任务授权/三方勾选；无需授权点击可执行提交；资产 collection_policy=default_return_all |
| 模板 | 教师 AI 生成模板后能编辑确认；学生自查用同模板版本；导出保留运行时模板快照 |
| 标注 | 学生与教师各保存两次人工记录，作者/轮次/版本/区块/字段/理由明确；AI 原建议仍在 |
| 版本 | 优化或重做产生新版本；旧版标注不漂移；无效版本、无效区块、空字段或短理由受阻 |
| 成品 | 两条 JSONL 可解析；关联步骤、版本、AI proposal 引用均存在；教师页可查看四个成品视图并下载 |
| 回归 | 整课、取回与手动提交、请修改重做、发布门禁、旧进度保留仍通过 |
| 视觉 | 320/768/1024/1440 无全页横向溢出；图/交付物标注可操作；步骤和区块按钮可键盘访问 |

AI 字段/模板草案未确认不冒充人工；执行失败保存失败记录且不增加成功事件；无产物不生成字段；当前提交之外的教师标注受阻。自动建议或字段缺少科学证据时由教师纠错，不能把结构完整等同科学正确。

## 9. 人机协同与质量

学生先判断并留下来源与不确定性，教师在可审计的产物和轨迹上作专家标注；AI降低录入与定位负担。多轮标注数据同时保留错误、专家纠正、学生修订与最终结果，形成可用于后续评测的数据结构。实际训练使用需真实审查与收益实验，本轮不验证。

## 10. 数据与权限

所有示例合成，默认任务数据回传不建立真实法律授权。当前无真实临床、企业或未公开数据。学生与教师仅在自己的角色范围标注，不能将 AI 自动建议标为人工；导出明确 synthetic_demo 和 training_used=false。旧授权字段不再作为本 Demo 使用逻辑，历史文件仅保留版本记录。

## 11. 开放问题与风险

生产真实工具事件接入、run 计时来源、文件 diff 与图像坐标标注、跨版锚点迁移、真实 rubric/字段 schema、专家一致性、数据协议与训练许可、训练/评测隔离、真实科学质量与模型提升待验证。本轮图像标注到图/图注区块，未做像素坐标绘制；轨迹概览为点击定位，不做完整缩放拖选或海量虚拟化。
